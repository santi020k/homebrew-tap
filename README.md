# Santi020k Homebrew Tap

Homebrew formulae for Santi020k developer tools.

## Install Santi020k Terminal

```sh
brew install santi020k/tap/santi020k-terminal
santi020k-terminal install
```

The formula installs the Santi020k terminal CLI, terminal color presets, Starship configurations, curated Zsh setup, and their Homebrew dependencies.

## Upgrade

```sh
brew update
brew upgrade santi020k-terminal
santi020k-terminal update
```

## Development

Product source, tests, and release archives live in [santi020k/santi020k-theme](https://github.com/santi020k/santi020k-theme). This repository contains only Homebrew packaging metadata.

`Formula/santi020k-terminal.rb` is generated and updated by the terminal release workflow. Do not duplicate the product source in this repository.
